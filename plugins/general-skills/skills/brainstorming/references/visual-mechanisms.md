# Visual mechanisms

Use selectively for a new visual concept, not as compulsory styles. Choose mechanisms that clarify the message; preserve approved identities and series. Read this local reference only for relevant visual work.

### V01 Symbolic pairing
Let one visible thing communicate an otherwise abstract idea.

### V02 Meaningful replacement
Exchange an expected element for something that explains the subject.

### V03 Figure-ground reveal
Use a gap or silhouette to carry a second reading.

### V04 Relational sizing
Make a size relationship communicate importance, dependence or consequence.

### V05 Intrinsic geometry
Let the subject's real structure organize the composition.

### V06 Expressive lettering
Give lettering a behavior connected to the message; retain legibility.

### V07 Performative composition
Make the layout demonstrate the action being described.

### V08 Close-detail reveal
Use a significant detail to invite recognition, not arbitrary cropping.

### V09 Reference-code contrast
Combine audience-familiar visual conventions to create a relevant tension.

### V10 Single visual joke
Build one understandable surprise instead of stacking decorations.
