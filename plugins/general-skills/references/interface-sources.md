# Nine-source adoption register

Reviewed 2026-10-17 for the user-approved shortlist. These URLs credit the inspected primary material; main-branch documents may change. They are not executable dependency pins or evidence of an installed connection. Recheck current technical/access terms when actually using a provider. No third-party prompt, binary, screenshot library or font is bundled in General Skills. See [interface practice](interface-practice.md) for the adapted methods.

## S01 — Emil Kowalski

[Skills](https://github.com/emilkowalski/skills): `skills/break-ui/SKILL.md`, `skills/prototype/SKILL.md`, `skills/animate/SKILL.md`, `skills/animation-performance/SKILL.md`. Adopt real-input stress, working preview variants, interruption-aware transitions and measured profiling. Route to Genjutsu and Motion Design. Do not import universal style/duration rules or install the full package.

## S02 — Impeccable

[Source](https://github.com/pbakaus/impeccable): `skill/SKILL.src.md`, `skill/reference/harden.md`, `skill/reference/clarify.md`, README. Adopt screen-purpose reasoning, recovery and actionable language. Route to Genjutsu. Do not import its binary, edit hooks, remote direction API or telemetry machinery. Optional data sources do not become execution authority.

## S03 — Taste Skill

[Inspector](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/scripts/inspect.mjs). Adopt the measurement questions, not its implementation or taste verdict. The parent repository contains an original browser observation helper. Exclude motion counts, arbitrary aesthetic scoring, implicit allowance files and destructive replacement of earlier screenshots.

## S04 — Microsoft Playwright

[Visual comparisons](https://playwright.dev/docs/test-snapshots), [best practices](https://playwright.dev/docs/best-practices), [Docker](https://playwright.dev/python/docs/docker). Adopt action → behavioral assertion → screenshot, stable environments and explicit baseline review. Parent qualification uses Playwright 1.57.0; actual project versions are not silently upgraded. A snapshot is not business-logic or physical-device acceptance.

## S05 — Refero

[Official MCP](https://refero.design/mcp), [official skill repository](https://github.com/referodesign/refero_skill), [terms](https://doc.refero.design/legal/terms-of-use), especially sections 12–15. Adopt authorized complete-flow research in Design DNA and Competitor Recon. Access is optional, not bundled. No model training, fine-tuning, evaluation, benchmarks, AI-improvement datasets, bulk extraction or redistribution without applicable separate permission. No Refero content is used in our qualification fixtures.

## S06 — Details

[Inspo](https://www.details.so/inspo). Adopt section-specific research for a hero, navigation, demonstration or transition. Treat references, Remix and copy-ready code as different capabilities with separate access/reuse checks. Do not infer a license to copy a whole site or install its MCP merely from a gallery listing.

## S07 — Design Spells

[Gallery](https://designspells.com/). Adopt trigger/state/feedback/cancellation descriptions for motion references. Not a bundled code library or exporter. Reimplement with the target platform and verify behavior independently.

## S08 — Anthropic Frontend Design

[Skill source](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). Adopt content-led structure, meaningful first-screen demonstrations and clear consistent action vocabulary. Keep the user's approved choices; omit palette bans and overlapping full-process instructions. No additional frontend-design plugin is installed.

## S09 — Obscura

[Source and release](https://github.com/h4ckf0r0day/obscura/tree/v0.2.4), [benchmark methodology](https://github.com/h4ckf0r0day/obscura-benchmark), [CLI implementation](https://github.com/h4ckf0r0day/obscura/blob/v0.2.4/crates/obscura-cli/src/main.rs). Adopt only an isolated extraction pilot with exact expected fields, separate cold/reused timings and retained failures. The parent repository pins the no-render/no-stealth 0.2.4 archive by SHA-256; it remains outside production and visual QA. In this version combining --selector with --eval returns page output, not the eval value; the pilot uses the bare evaluation-output contract. A successful fetch/title or a completed experiment alone is not a passing extraction or blanket compatibility claim.
