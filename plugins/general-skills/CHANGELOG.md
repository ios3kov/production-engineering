# General Skills changelog

## 1.2.0 — 2026-10-17

Extend genjutsu, motion-design and design-dna with the accepted practices from the nine-source review. Preserve the earlier visual-production guidance and five unrelated skills. Purpose-led composition and truthful demonstrations; real-input stress and preview variants; recovery/copy; interruption and profiling; authorized reference research. Sources, exclusions and access boundaries are kept in optional local references. No global instruction injection, external API, binary helper, motion score or new plugin dependency.

Browser fixtures in the parent repository qualify an original measurement helper; they are not application or live agent acceptance. Obscura is a separately isolated extraction experiment, not a visual-QA replacement. Exact execution results belong to the parent repository's adoption record and CI artifacts, not to a claim that prose improves model output.

## 1.1.0 — 2026-10-17

Scope: the two existing skills `brainstorming` and `genjutsu`, with optional local references. No new skill, executable tool, dependency, hook, network permission or AS/AE rule is added. `design-dna` and the other five skills keep their previous bytes.

Accepted additions:

1. A [ten-mechanism visual library](skills/brainstorming/references/visual-mechanisms.md), loaded only for visual ideation.
2. A subject-relevance check that permits useful templates and recurring brand systems.
3. A [production brief](skills/genjutsu/references/visual-production.md) covering dimensions, crops, text, treatment and invariants.
4. Identity preservation and truthful product demonstrations, including FSTR outputs.
5. Separate message, audience, concept and execution assessment.
6. Cause-specific repair, with a different production method for repeated failures.

These extend existing ideation and review steps; they do not duplicate them. User preferences, approved palettes and platform UX remain authoritative. Source activation/reset commands, palette bans, forced poster style, automatic full redesigns and mandatory remote rereading are excluded. Attribution is in each reference; source prompts/images are not bundled and no source reuse license is assumed.

Verification: `scripts/tests/test_general_skills.py` checks packaging/version; `scripts/tests/test_visual_skills.py` checks reference links, the ten-item inventory and retained text contracts. Actual results belong to the exact commit's CI run. These are structural/content regression tests, not live agent trials or evidence of better image quality. Image generation and comparative agent evaluation are NOT_RUN for this text-only update.

Acceptance review examples: a one-word correction retains the composition; an approved black-and-gold campaign keeps its palette; a new cover may explore mechanisms; a long text layout preserves all required copy; an FSTR concept is not presented as a tested effect; unavailable rendering/inspection is disclosed rather than claimed complete.
